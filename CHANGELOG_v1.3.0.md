# Iris v1.3.0 — Avisos a tiempo

**Fecha:** 2026-11-20

## Problema que resuelve
Notificaciones tarde o poco visibles → el usuario no se entera y pierde la actividad.

## Cambios
- Anticipación por tipo (reunión, preparación, trabajo, rápidos)
- Doble aviso: temprano + cercano (10–15 min)
- Recuperación única si no hay respuesta
- Señal “en riesgo” en el resumen diario
- Un poco más directa: prioriza enterarse a tiempo sobre el silencio total
- Sigue siendo fácil posponer en cada aviso
